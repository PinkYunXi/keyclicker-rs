# KeyClicker 0.9.0-alpha

Windows 键盘连点 / 定时按键工具，用 **Rust + WebView2** 重写（旧版为 Python + PyQt6）。

- **单文件 exe**（约 4 MB，UI 资源与 WebView2 安装器均已内嵌）
- 深/浅色 Fluent 界面，无边框圆角窗口
- 连点间隔下限 16 ms（约 60 次/秒）
- 所有数据只存本地，不联网、不上传

## 功能

- **连点**：固定间隔发送按键/组合键，实时计数，可暂停/继续/停止
- **定时序列**：分+秒倒计时，到点依次发送一串按键，支持循环与步骤间隔
- **按键录入**：点「● 录入」后直接按键盘，Esc 取消；钩子失效时自动回退到页面捕获
- **前台窗口锁定**：包含 / 精确 / 正则三种匹配，不匹配时不发送也不计数
- **抓取当前窗口**：3 秒倒数后取前台窗口标题（拒绝抓取本程序自身）
- **多配置页**：新增/重命名/删除，改动自动保存（临时文件 + 原子替换）
- **全局热键**：`Alt + \` ` 开始/停止当前页，`F6` 暂停/恢复全部（系统级注册，任何窗口下可用）
- **托盘**：显示主窗口 / 开始当前页 / 暂停恢复 / 退出
- **单实例**：重复启动会提示
- **主题**：深色 / 浅色 / 跟随系统
- **兼容旧配置**：直接读取旧版 `clicker_config.json`（v2 与顶层数组格式）

## 系统要求

- Windows 10 1809+ / Windows 11
- WebView2 运行时：Windows 11 自带；**Windows 10 缺少时程序会自动提示并静默安装**

## 使用

1. 下载 `KeyClicker.exe`，双击运行（绿色单文件，配置写在 exe 同目录 `clicker_config.json`）
2. 连点：填按键 → 设间隔 → 添加到任务列表 → ▶ 开始
3. 定时序列：「设置序列」录入按键 → 设分/秒 → 添加
4. 需要只在某个窗口生效时，填窗口关键词（或「抓取当前窗口」）并选择匹配方式

## 快捷键

| 热键 | 作用 |
| --- | --- |
| `Alt` + `` ` `` | 开始 / 停止当前配置页全部任务 |
| `F6` | 暂停 / 恢复全部任务 |

## 构建

```bat
:: 需要 Rust（MSVC 工具链）+ VS Build Tools
cargo build --release
:: 产物：target\release\keyclicker-rs.exe
```

发布版会先运行 `tools/gen_ui_assets.py` 把 `ui/` 内嵌进 exe，再由 `build.bat` 一键编译并部署。

## 已知限制（alpha）

- 需以不低于目标程序的权限运行（向管理员程序发键需右键以管理员运行）
- 窗口匹配的正则为大小写不敏感的部分匹配
- 托盘图标为通用图标，尚未做右键菜单的多语言
