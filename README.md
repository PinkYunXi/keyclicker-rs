# KeyClicker 0.9.0-beta

一个轻量的 Windows 键盘连点 / 定时按键工具。单文件绿色版，深色与浅色主题，配置全部保存在本地。

- **单文件 exe**（约 2 MB，界面资源全部内嵌，无外部依赖）
- 深/浅色 Fluent 界面，无边框圆角窗口
- 连点间隔下限 16 ms（约 60 次/秒）
- 所有数据只存本地，不联网、不上传

> Windows 发布版已申请 [SignPath Foundation](https://signpath.org/) 提供的开源项目免费代码签名。

## 功能

- **连点**：按固定间隔反复发送按键或组合键，实时计数，可暂停 / 继续 / 停止
- **定时序列**：分 + 秒倒计时，到点依次发送一串按键，支持步骤间隔
- **按键录入**：点「录入」后直接按键盘，自动识别组合键，Esc 取消
- **前台窗口锁定**：包含 / 精确 / 正则三种匹配方式，窗口不匹配时不发送也不计数
- **抓取当前窗口**：倒数后自动填入当前前台窗口标题
- **多配置页**：新增 / 重命名 / 删除，改动自动保存
- **全局热键**：`Alt` + &#96; 启停当前选中的配置，`F6` 启停全部配置
- **托盘**：左键单击显示主界面；右键菜单为「显示主界面 / 设置… / 退出」
- **关闭方式**：首次点 ✕ 会询问「最小化到托盘」还是「直接退出」，可勾选「下次不再提示」记住选择
- **设置面板**：标题栏齿轮或托盘「设置…」打开，可改关闭行为、删除确认、全局热键、主题
- **单实例**：重复启动会唤起已有窗口
- **主题**：深色 / 浅色 / 跟随系统
- **兼容旧配置**：可直接读取旧版本的 `clicker_config.json`

## 系统要求

- Windows 10 1809+ / Windows 11（**仅 x64**）
- WebView2 运行时：Windows 11 自带；Windows 10 缺少时会提示并打开微软官方下载页

## 使用

1. 下载 `KeyClicker-0.9.0-beta-x64.exe`，双击运行（绿色单文件，配置写在 exe 同目录 `clicker_config.json`）
2. 连点：填按键 → 设间隔 → 添加到任务列表 → 点 ▶ 开始
3. 定时序列：「设置序列」录入按键 → 设分 / 秒 → 添加
4. 需要只在某个窗口生效时，填窗口关键词（或点「抓取当前窗口」）并选择匹配方式

## 快捷键

| 热键 | 作用 |
| --- | --- |
| `Alt` + &#96; | 开始 / 停止**当前选中配置**的全部任务 |
| `F6` | 开始 / 停止**全部配置**（所有页）的任务 |

热键可在设置面板里修改，改完立即生效并保存。

## 从源码构建

需要 Rust（MSVC 工具链）与 Visual Studio Build Tools：

```bat
python tools/gen_ui_assets.py
cargo build --release
:: 产物：target\release\keyclicker-rs.exe
```

`gen_ui_assets.py` 会把 `ui/` 目录下的界面资源内嵌进 exe；`build.bat` 可一键完成「生成资源 + 编译 + 部署」。

## 已知限制

- 仅支持 x64
- 需以不低于目标程序的权限运行（向管理员程序发键需以管理员身份运行本程序）
- 窗口匹配的正则为大小写不敏感的部分匹配
- 窗口尺寸限制在 720×520 ~ 1120×800，不支持最大化
- 部分全屏独占游戏内可能被反作弊拦截
